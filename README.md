# 红包上写什么

一个单页小工具：选「场合」+「关系」，立刻给出

- **封面题字**（竖排，照着抄到红包上）
- **落款**（名字 + 敬贺／敬挽）
- **背面小字**（聊表心意 敬请笑纳）
- **微信备注**（转账时那一句）
- **见面那句**（当面怎么开口）
- **别踩的坑**（白事不能用红封、孩子别把「贵子／千金」写反、过寿别给三四十岁的人写寿联……）

再把整张卡**生成图片存进相册**。离线可用，没有账号，没有后台，不上报任何东西。

## 为什么做这个

红包上那几个字是当场要想、想不出来就尴尬的事。搜出来的是文章，不是「你这一场该怎么写」。这个工具只做一件事：把你手上这一场的字定下来。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 全部逻辑与样式（单文件，无依赖、无外链，可直接双击打开） |
| `manifest.webmanifest` | 添加到桌面（PWA） |
| `sw.js` | 离线缓存（仅在 http/https 下生效） |
| `icon.svg` | 图标 |

## 本地打开

双击 `index.html` 即可。也可以起个静态服务：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 部署

任意静态托管都行，无需构建：GitHub Pages / Cloudflare Pages / 国内对象存储 + CDN。
两个文件上传即可跑（`index.html` + `icon.svg`），能力加成（离线、桌面图标）再带 `sw.js` 与 `manifest.webmanifest`。

> 国内访问提示：github.io 在大陆不稳定。要给亲戚朋友用，建议挂 Cloudflare Pages 绑自己的域名，或放国内对象存储。

## 内容维护

所有文案集中在 `index.html` 顶部的 `OCCASIONS`（8 个场合）与 `RELATIONS`（6 种关系）两个数组里。加一个场合 = 复制一段对象、改 `titles` / `back` / `wx` / `say` / `taboo`。**不需要改任何逻辑。**

## 准确性的边界（重要）

题字是通行写法，但各地风俗差别很大：金额单双、信封颜色、能否空手进门、白事具体规矩，一律按当地来。
这个工具**不替你做决定，只帮你把字写对**。页面上也写了这句话。

## 许可

内容可自由取用。若要二次分发，请保留「拿不准就问同去的人」这句提醒——它是这个工具唯一的态度。
